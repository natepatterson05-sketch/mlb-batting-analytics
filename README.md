# The Shape of the Swing

An interactive data report and dashboard about major-league batting from 1871 through 2025, built by Nate Patterson for Financial Data Analytics.

## Live site

https://natepatterson05-sketch.github.io/mlb-batting-analytics/

## Data

The project uses the 1871–2025 release of the [SABR Lahman Baseball Database](https://sabr.org/lahman-database/), created by Sean Lahman and maintained by SABR. The source is licensed under CC BY-SA 3.0. One batting row represents one player’s statistics for one team stint in one season. The project includes 128,598 rows, 155 seasons, 24,011 players, and 21 browser-data columns.

No batting rows are removed. `People.csv` supplies player names and `Teams.csv` supplies historical team names. Missing counting-stat values are converted to zero. The dashboard reads `data/batting.csv` and performs all filtering and aggregation in the browser.

## Reproduce the project

On Windows PowerShell:

```powershell
./scripts/prepare-data.ps1
./scripts/build-report-data.ps1
```

Serve the repository directory over HTTP to test locally. Opening the HTML files directly with a `file://` URL will prevent browsers from loading the CSV.

## File guide

- `index.html` — scrolling report with headline numbers, eight findings, eight charts, and methodology.
- `dashboard.html` — interactive dashboard with four filters, measure and breakdown switches, four charts, KPIs, a data table, and reset control.
- `css/style.css` — shared responsive visual system for both pages.
- `css/ballpark-v8.css` — baseball-specific illustrations, animated base runner, vintage scoreboard finding panels, and responsive visual details.
- `assets/championship-trophy.svg` — original baseball championship trophy illustration used as a report background accent.
- `js/report-labeled.js` — loads precomputed report results and draws the eight labeled report charts.
- `js/home-run-animation-loop.js` — triggers and synchronizes the looping first-finding home-run animation when it enters view.
- `css/home-run-v3.css` — isolated looping styling for the first-finding animation.
- `js/dashboard.js` — loads and parses the row-level CSV, filters it, calculates summaries, draws charts, and updates the table.
- `data/batting.csv` — browser-ready panel dataset produced from the three source tables.
- `data/metadata.json` — dataset dimensions generated by the preparation script.
- `data/report.json` — reproducible aggregates used by the report charts.
- `source-data/Batting.csv` — unmodified SABR/Lahman player-season/team-stint batting table.
- `source-data/People.csv` — unmodified player lookup table.
- `source-data/Teams.csv` — unmodified historical team lookup table.
- `source-data/README.md` — source-data note and download location.
- `scripts/prepare-data.ps1` — joins names to batting rows and exports the browser dataset.
- `scripts/build-report-data.ps1` — computes every report series directly from the browser dataset.
- `submission.md` — four-line submission template.

## Definitions

- Batting average = hits / at-bats.
- Per-100-AB rate = statistic / at-bats × 100.
- Career values sum all player-team stints.
- Team-season values sum all player rows for a team and year.
- The career batting-average ranking requires at least 3,000 at-bats.
